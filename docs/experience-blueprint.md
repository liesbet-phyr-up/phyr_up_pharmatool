# Maximed Learning Platform Experience Blueprint

The platform uses a shared Maximed brand shell but separates working modes by role. It is designed mobile-first for field and sales learners, while preserving dense, filterable reporting views on larger screens for teaching staff and administrators.

| Area | Primary user | Purpose | Primary navigation |
|---|---|---|---|
| Learning home | Learner | Show required learning, recent progress, and pathway categories. | My learning, pathways, profile. |
| Course workspace | Learner | Complete sequential lessons, resources, acknowledgements, and quizzes. | Back to learning, module outline, continue action. |
| Training dashboard | Trainer | Review organisation-wide completion and assessment performance. | Overview, learners, results. |
| Administration | Admin | Manage users, roles, organisation data, and reporting dimensions. | Overview, people, learning catalogue. |

## Layout principles

The learner experience uses a light header, short maximum line lengths, large touch controls, and a single priority action per screen. Training and administration views use a compact left navigation rail on desktop and a menu sheet on mobile. Information is surfaced in a limited set of cards, data tables, and filter controls rather than decorative panels.

## Visual principles

White is used for calm, readable work surfaces. Maximed blue provides the primary structure and trusted actions; Maximed red is reserved for important actions and urgent states. Nunito Sans provides the main product typography, with Montserrat used sparingly for small brand labels. Motion is limited to quick hover, focus, and panel transitions and respects reduced-motion preferences.
